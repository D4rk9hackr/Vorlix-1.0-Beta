# Vorlix Benchmark Results

Comparison of Vorlix (tiered escalation) against a simulated vision-based Computer Use loop for 10 common automation tasks.

> **Important:** The Computer Use column is a *simulation* based on published token-cost figures (~1500 tokens per screenshot image encoding per [Anthropic's documentation](https://docs.anthropic.com/en/docs/build-with-claude/computer-use), plus ~750 tokens per analysis step). It is not a live comparison against any specific product.

- *Open a specific application* — handled by **terminal** in 19ms with ~200 tokens. A CV loop would need ~4500 tokens and ~9000ms — Vorlix is faster by avoiding screenshot capture and vision-model inference entirely.

- *Read a value from a config file* — handled by **file_io** in 6ms with ~100 tokens. A CV loop would need ~2250 tokens and ~4500ms — Vorlix is faster by avoiding screenshot capture and vision-model inference entirely.

- *Create a scheduled reminder* — handled by **time_reminders** in 20ms with ~200 tokens. A CV loop would need ~4500 tokens and ~9000ms — Vorlix is faster by avoiding screenshot capture and vision-model inference entirely.

## Caveats

1. **Vorlix tokens shown are estimates** — minimal LLM overhead for tool choice (~100 tokens per action). A real agent may spend more on planning.

2. **CV time estimates are conservative** — actual vision-loop latency can be higher due to network latency, cold starts, and rate limits.

3. **Single-run measurements** — wall-clock times vary with system load.
